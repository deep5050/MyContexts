# MyContexts

MyContexts is a project aimed at integrating useful right-click context menus for different file types. This tool enhances productivity by providing quick access to common actions based on the file type you are working with.

## Features

- Customizable context menus for various file types
- Easy to configure and extend
- Lightweight and fast

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/MyContexts.git
    ```
2. Navigate to the project directory:
    ```sh
    cd MyContexts
    ```
3. Follow the setup instructions in the [INSTALL.md](INSTALL.md) file.

## Usage

1. Right-click on a file to see the custom context menu.
2. Select the desired action from the menu.
